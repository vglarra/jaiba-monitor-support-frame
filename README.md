# Jaiba Monitor Support Frame

Parametric, 3D-printable monitor stand with **tilt (0–45° / 0–90° depending on variant), swivel (±45°) and horizontal slide**. Everything is generated by Blender Python scripts, exported as print-ready STLs (in mm), and printed in ASA.

The repo contains two generators and two finished designs:

| Script | Design | Output prefix |
|---|---|---|
| `make_stand.py` | Original stand for a 7" PCB/glass monitor (holds the PCB on a tray with a foldable cap) | `mon1_7in_v14` |
| `make_stand_mon2.py` | Larger stand for an 11.6" cased monitor on a **VESA 75×75** plate | `mon2_11in6_v14_m6swivel` |
| `make_stand_mon2 (1).py` | Same as above, but with a **middle-ear spacer** and 0–90° tilt | `mon2_11in6_v15_spacer` |

Two `*.blend` assembly files are included for viewing/editing the finished assemblies:

- `mon2_11in6_v14_m6swivel_assembly.blend`
- `mon2_11in6_v15_spacer_assembly.blend`

## Mechanism overview

All stands share the same three-axis rig, driven by nested empties with rotation/location limits:

- **SLIDE** — the whole head moves left/right on a dovetail-style carriage `slide +-N mm` (different per variant).
- **SWIVEL** — the turntable rotates `±45°` about the vertical axis, stopped by a post against an arc groove.
- **TILT** — the monitor holder tilts about a hinge axis, limited by a stop screw riding in an arc groove.
- **LID_HINGE** — *(mon1 only)* the foldable screen cap, opens up to 270°.

The base is a hollow, rib-grid block so it prints fast and light while staying stiff. The tilt hinge is a stack of **lugs** (on the monitor holder) and **ears** (on the turntable); a bolt through the stack plus a wing nut / star knob set the friction and hold the chosen angle.

```
        monitor / VESA plate
                 │
        [ tilt hinge ]──── frame lugs ⇄ turntable ears ── bolt + wing nut
                 │
          [ turntable ]──── swivel ±45° (post in arc groove)
                 │
         [ carriage  ]──── slides left/right in a channel
                 │
              [ base ]──── rib-grid underside, rubber feet
```

## Printed parts

| Part | Role |
|---|---|
| **base** | Rib-grid block with the turntable recess, slide channel, and (mon2) the lock screw tunnels/nut slots. Rubber feet recesses underneath. |
| **carriage** | Slides in the channel under the turntable, carries the swivel-stop post so the ±45° limit works at every slide position. |
| **turntable** | Rotates on the base and carries the tilt hinge ears and the swivel-stop groove. |
| **frame** | The monitor holder. On mon1 it is a PCB tray with corner guards + standoffs; on mon2 it is a flat VESA 75×75 plate with rails and a wiring bay. |
| **lid** *(mon1)* | Foldable screen cap hinged on the top edge with snap latches. |
| **lockblock** *(mon2)* | Choke block that clamps the turntable rim for the swivel + slide lock. |
| **spacer** *(v15)* | Cylindrical filler for the removed middle turntable ear — keeps the hinge stack solid where the swivel nut drops in. |

## Hardware

Hardware differs per variant; the BOM is printed at the end of every run. Summary:

### mon2 (11.6" VESA stand)

- **Tilt hinge:** 1× M6 hex-head bolt (head in the left outer frame lug pocket) + 2× M6 washers + M6 star knob D25 (female thread) on the right face. Whole hinge stack is a 10-lug / 9-ear clevis (18 friction faces).
- **VESA plate:** 4× M4 socket-head screws (heads sunk in counterbores on the back of the plate).
- **Swivel:** M6×14 hex bolt + captured M6 nut (10 mm AF); 4× M3×10 tilt-stop screws in the frame outer lugs.
- **Lock:** 2× M6×25 knurled thumb screws + 2× M6 hex nuts + 1 printed lockblock.
- 4× self-adhesive rubber feet.

### mon1 (7" PCB stand)

- 1× M5 bolt + nut — swivel axis
- 1× M4 bolt + nut (+ washer, lock nut) — tilt hinge, with M4 wing nut
- 2× M3×8 button-head — tilt stops
- 4× M3 socket-cap ×14–16 + nuts — PCB mounting
- 3× M3×16 + nyloc nuts — cap hinge pins
- 4× rubber feet

Always dry-fit and measure your actual screws; lengths quoted are minimums and hardware may protrude through through-threaded knobs.

## Usage

Requires **Blender** (bpy) and Python 3. The scripts use Blender's exact boolean solver.

```bash
# run with bpy inside Blender (headless)
blender -b -P make_stand_mon2.py -- --out ./out2
blender -b -P "make_stand_mon2 (1).py" -- --out ./out3

# or with the pip bpy module
python -I make_stand_mon2.py --out ./out2
```

Outputs land in the `--out` folder (default `./out`, `./out2`, …):

- one STL per part, in print orientation
- an `*_assembly.blend` of the full mechanism
- `preview_*.png` workbench renders

Each run also prints, to the console:

- **Non-manifold edge counts** per part (should be 0)
- **Base footprint / volume** (solid vs. with the rib pockets)
- **A load-path hand calculation** (mon2): bending stress in the lug ribs, plate, VESA screw bearing, rail and bolt — assumptions are conservative and printed alongside
- **Interference checks**: full tilt × swivel × slide sweep, bolt-triangle overlap detection, tipping margin (monitor CG vs. base footprint), minimum monitor clearance
- **Stop tests**: that the tilt and swivel stops engage at the right angles
- **Hardware BOM** sized from the geometry

A clean run ends with `ALL CLEAR`.

## Tuning a design

All parameters live in the `CFG_*` dicts at the top of each script (`CFG_MONITOR1` in `make_stand.py`, `CFG2` in the mon2 scripts). Notable knobs:

| Parameter | Meaning |
|---|---|
| `base_l`, `tt_r`, `tt_t`, `base_t` | Base width, turntable radius/thickness, base height (`base_t = floor_t + tt_t` keeps the top flush). |
| `slide_travel` | Horizontal slide range (±). |
| `tilt_max`, `swivel_max` | Angle limits. |
| `n_lugs`, `lug_w`, `lug_w_outer`, `ear_t`, `ear_gap` | Hinge stack layout / friction faces. |
| `lug_r`, `lug_clear` | Hinge disc radius and radial clearance. |
| `plate_t`, `standoff`, `vesa`, `vesa_yc` | mon2 VESA plate thickness, wiring-bay rail height, hole pitch and centre height. |
| `body_w`, `body_t`, `box_*` | Monitor envelope (collision dummy only, not exported). |
| `mon_mass`, `dyn` | Mass and dynamic knock factor used by the stress report. |
| `cav_wall`, `cav_rib`, `cav_cell` | Underside rib grid (weight vs. stiffness). |
| `spacer_lift` | v15 only: radial gap of the middle-ear spacer. |

Re-running regenerates every part and re-runs the checks, so change parameters, re-run, and read the printed stress/clearance report before printing.

## Printing notes

- **Material:** ASA (the declared design intent); PETG works as a fallback.
- **Orientation:** each STL is already oriented to print flat — do not re-orient the base or frame.
- **Supports:** none needed except inside the small bolt holes and the hinge bore.
- **Perimeters:** use at least 3–4 walls on load-bearing parts (base, turntable, frame lugs).
- **Friction faces:** print the hinge lugs/ears cleanly; the wing nut / star knob clamp load is what holds the tilt angle, so surface finish matters.
- **Scale:** all files are in **mm**. Confirm your slicer is set to mm and 100% scale.

See the header docstring of `make_stand.py` for the original print/hardware notes.
